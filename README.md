# jhayrdmz.github.io

My personal website and portfolio, hosted on GitHub Pages.

**Live site:** https://jhayrdmz.github.io

## Structure

```
index.html     Home page (about, experience, stack, portfolio)
projects/      Individual project pages
css/           Stylesheets
js/            Scripts
images/        Photos, client logos, icons and screenshots
fonts/         Web fonts
```

## Run locally

It's a static site, so you can serve it with any local web server:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Push to `main` and GitHub Pages publishes the site automatically.
